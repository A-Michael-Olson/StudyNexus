# StudyNexus

## Team Members
 James Stolte, Mike Olson, Kaitlin Heusner, Graham McClure
 
## Software Description
A group study planner/collaboration website that invites people working together to have
a shared space where people can work together, keep each other accountable, and add
tasks. This will include having a group where people can communicate as well as add, 
remove, and manage tasks. File sharing will be available within these groups. Also, there will
be a space for people to work together with a timer and chat. 

## Architecture
The architecture that we are going to use is: HTML, CSS, JavaScript, Visual Studio Code, Supabase, and GitHub.  

## Software Features

* [x] Add tasks to complete in group
* [x] Mark off tasks to complete in group
* [x] Message each other in dashboard
* [x] View profile
* [x] Change username
* [x] Change profile picture
* [x] Create channels (messaging or whiteboard)
* [x] Create whiteboard that everyone can interact with at the same time
* [x] Can turn on light/dark mode
* [x] Leave Group
* [x] Join Group

## Reflections
* We learned how to effectively work with one another by learning how to organize and divide tasks. We also learned how to manage GitHub when working as a team to avoid any merge conflicts. Futhermore, we learned how to use Supabase, which was a big component of our project as it was where we stored all of the important information that we used in the project. Also, we learned how to implement networking and realtime features in our project via messaging and the interactive whiteboard. 
*  The mobile version of the site could be improved to make user experiences more seamless and easier to use. Additionally, we could add the erase option for the white board so that people can effectively fix or remove what they have put on it. Furthermore, we could add more security protections to ensure that people who just join the group do not have the same administrative access as owners of the group. We could also implement the create group feature so that users can create their own groups to use.
*  Our future plans are the following: we would plan to integrate a voice call feature. Furthermore, we would want to have a server that we could use to host the site instead of GitHub. Also, implementing permissions so that only certain users can perform certain actions in a group. Lastly, allowing users to upload files into the chat and store them so that everyone can access them.
